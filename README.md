# Diário de Bordo – PWA

Aplicação Progressive Web App desenvolvida como atividade prática do curso Full Stack Python da EBAC.

## Funcionalidades

- Cadastro de atividades com título, descrição e data.
- Listagem e exclusão de registros.
- Persistência de dados com localStorage.
- Funcionamento offline com Service Worker.
- Instalação como aplicativo.
- Interface responsiva para desktop e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Web App Manifest
- Service Worker
- LocalStorage
- GitHub Pages

## Como executar

Acesse a aplicação publicada pelo GitHub Pages ou execute o projeto utilizando um servidor HTTP local.

## Funcionamento offline

Após o primeiro acesso com conexão à internet e a instalação do Service Worker, os arquivos da aplicação ficam armazenados em cache, permitindo o uso offline.

Os registros são armazenados localmente no navegador, permanecendo disponíveis após recarregar a página.
